# Gemini市場調査ガイド

## 目的

プロダクト仕様の妥当性を検証するため、Geminiに最新の市場動向・競合分析・類似プロダクト事例を調査依頼する。

## 調査プロンプトテンプレート

```
以下のプロダクト仕様について、2026年2月時点の最新情報で市場調査を実施してください。

【プロダクト概要】
{product.mdのシステム概要を要約}

【ターゲット】
{product.mdのターゲットユーザー}

【解決する課題】
{product.mdの解決する課題}

【調査項目】
1. **競合・類似プロダクト分析**
   - 同じ課題を解決する既存製品（3-5件）
   - 各製品の強み・弱み・価格・ユーザー評価
   - 最新の市場トレンド（2024-2026年）

2. **成功/失敗事例**
   - 類似コンセプトで成功したプロダクト（2件以上）
   - 失敗したプロダクトとその原因（2件以上）
   - 成功要因・失敗要因の分析

3. **市場機会の評価**
   - 市場規模・成長率（TAM/SAM/SOM）
   - 参入障壁・競合優位性の実現可能性
   - 現在の市場ギャップ

4. **リスク評価**
   - 市場リスク（競合の動き、市場縮小等）
   - 技術的リスク（実現困難性、陳腐化等）
   - 規制・コンプライアンスリスク

5. **推奨事項**
   - このプロダクトの実現可能性評価（5段階）
   - 差別化ポイントの妥当性
   - 追加すべき機能・削除すべき機能
   - 優先すべきターゲットセグメント

【出力形式】
構造化JSON形式で、各項目に具体的なデータ・事例・URLを含めてください。
```

## 出力の活用

- 調査結果を `.dgic/logs/spec-init_market_research_YYYYMMDD.json` に保存
- product.md作成後、ユーザーに調査結果のサマリーを提示
- 競合優位性・リスクの再確認を促す
- 必要に応じてproduct.mdの修正を提案
