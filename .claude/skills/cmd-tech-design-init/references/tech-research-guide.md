# Gemini技術調査ガイド

## 目的

tech_stack.mdで選定された技術について、2026年2月時点の最新情報・評判・ベストプラクティスをGeminiで調査する。

## 調査プロンプトテンプレート

```
以下の技術スタックについて、2026年2月時点の最新情報を調査してください。

【プロダクト概要】
{product.mdの要約}

【選定済み技術スタック】
{tech_stack.mdの技術一覧}

【調査項目】
1. **各技術の最新状況（2026年2月）**
   - 最新安定版バージョン・リリース日
   - 次期メジャーバージョン予定
   - サポート状況・EOL予定
   - コミュニティ活動度（GitHub Stars, Commits, Contributors）

2. **評判・採用状況**
   - 大手企業の採用事例（2024-2026年）
   - Stack Overflow/Reddit/Hacker Newsでの評価
   - 既知の重大な問題・脆弱性（CVE情報）
   - パフォーマンス・セキュリティベンチマーク

3. **2026年のベストプラクティス**
   - 推奨される構成・アーキテクチャパターン
   - 必須の周辺ツール（Linter/Formatter/Test/CI/CD）
   - セキュリティ設定（OWASP準拠）
   - パフォーマンス最適化手法

4. **代替技術の最新動向**
   - tech_stack.mdで不採用とした技術の現状
   - 新興技術で検討すべきもの（2025-2026年登場）
   - 選定技術と代替案の最新比較

5. **AI統合・LLM対応**
   - LLM/AI機能との統合容易性
   - Context Engineering対応状況
   - AI駆動開発ツールの利用可能性

6. **移行・運用リスク**
   - 既知の移行時の落とし穴
   - スケーリング時の問題
   - ライセンス変更・価格変更の動向

【出力形式】
技術ごとに構造化JSON形式で、具体的なバージョン番号・URL・数値データを含めてください。
```

## 出力の活用

- 調査結果を `.dgic/logs/tech-design-init_research_YYYYMMDD.json` に保存
- 最新バージョン・脆弱性情報をtech_stack.mdに反映
- 重大な問題（EOL間近、セキュリティ脆弱性等）があれば即座に通知
- 代替技術の検討を促す
