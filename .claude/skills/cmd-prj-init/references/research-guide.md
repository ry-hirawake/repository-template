# Gemini 調査ガイド

## 調査プロンプトテンプレート

```
以下の技術スタックの2026年最新のベストプラクティスを調査してください:

【技術スタック】
{tech_stack}

【プロジェクト概要】
{product_summary}

【調査項目】
1. 最新推奨バージョン・依存関係
2. プロジェクト構造（ディレクトリ・ファイル配置）
3. 開発環境設定（Linter, Formatter, Test）
4. セキュリティベストプラクティス
5. パフォーマンス最適化
6. Docker/コンテナ化の推奨
7. CI/CD推奨構成
8. 避けるべきアンチパターン

【出力形式】
構造化されたJSON形式で返してください。
各項目に具体的なコマンド・設定例を含めること。
```

## 調査結果の活用

Geminiが返す情報を元に:
- プロジェクト生成コマンド組み立て
- 設定ファイルテンプレート生成
- ドキュメント生成

## フォールバック

Gemini調査失敗時:
- 公式ドキュメントURL提示
- 基本構成での生成を提案
- ユーザーに手動設定を依頼
