# 言語ルール

## 思考と推論

- **常に英語で考え、推論する**
- 内部分析、計画、問題解決は英語で行う
- 変数名、関数名は英語で行う
- コードコメント、ドキュメント文字列は日本語で行う

## ユーザーとのコミュニケーション

- **ユーザーへの返信は常に日本語で行う**
- 説明、質問、ステータス更新は日本語で行う
- ユーザーに表示されるエラーメッセージは日本語で行う

## コード

- すべてのコードは英語で記述する
- 変数名: `user_count` を使用する。`ユーザー数` は使用しない
- 関数名: `calculate_total()` を使用する。`合計計算()` は使用しない
- コメント: `# 有効かどうかチェック` を使用する。`# Check if valid` は使用しない
- ドキュメント文字列: 日本語で記述する

## ドキュメント

- 技術ドキュメント: 日本語
- ユーザー向けドキュメント (README など): 日本語
